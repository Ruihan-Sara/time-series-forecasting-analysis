Time series forecasting project comparing statistical models using R and Kaggle competition data.
# Time Series Forecasting Competition

## Overview

This project applies statistical forecasting methods to predict 600 time series in a Kaggle forecasting competition.

## Objectives

The project evaluates different forecasting approaches and identifies the most effective model based on predictive accuracy.

## Methods

Models tested:

- TBATS
- Auto ARIMA
- Linear Regression with time covariates

## Evaluation

Models were compared using:

- Cross-validation
- Mean Absolute Error (MAE)
- Kaggle competition score
